# qq-style

Канон русского объясняющего текста без примет машинного письма, в трёх
формах из одного источника: документ для людей, скилл для агентов и
проверялка для сборки. Родился в курсе «Учи Кванты!» и Лаборатории, где
тексты пишутся и людьми, и языковыми моделями, а читают их ученики.

Скилл отличается от «очеловечивателей» тем, чего не делает: он не учит
прятаться от детекторов, не добавляет рваный ритм и иронию. Его задача, чтобы
текст объяснял, а не перечислял, и чтобы читатель ему доверял.

## Состав

| Файл | Что это | Для кого |
|---|---|---|
| `RULES.md` | полный канон с примерами «плохо / лучше», три слоя | люди и модели |
| `GLOSSARY-qq.md` | словарь проекта «Учи Кванты!» (пример третьего слоя) | люди |
| `rules.toml` | машинная часть первого слоя: запреты, исключения для тире, порог слов | проверялка и сборщик |
| `glossary-qq.toml` | машинная часть словаря проекта | проверялка |
| `check_texts.py` | проверка md, txt, ipynb, py, html по правилам | CI, сборка, ручной запуск |
| `SKILL.md` | скилл для Claude Code, Claude.ai, Codex, Cursor (собирается) | агенты |
| `PROMPT.md` | сжатая версия для системного промпта любой LLM (собирается) | ChatGPT, Gemini, Kimi, YandexGPT |
| `build.py` | собирает `SKILL.md` и `PROMPT.md` из шаблонов и `rules.toml` | сопровождение |
| `examples/` | пары «до / после» | люди и модели |

## Как пользоваться

Репозиторий: https://github.com/poker26/qq-style

**Как скилл Claude Code.** Клонировать в `~/.claude/skills/qq-style/`
(лично) или в `.claude/skills/qq-style/` проекта:

```bash
git clone https://github.com/poker26/qq-style ~/.claude/skills/qq-style
``` Скилл срабатывает на
«проверь на робо-язык», «перепиши по канону» и при написании текстов для
читателя. В проекте со своим словарём положить рядом `GLOSSARY-<проект>.md` и
`glossary-<проект>.toml`.

**Как системный промпт.** Содержимое `PROMPT.md` вставить в инструкции модели
или в `AGENTS.md`.

**Как проверка в сборке.**

```bash
python check_texts.py content/lessons                        # общий слой
python check_texts.py --glossary glossary-qq.toml notebooks  # плюс словарь проекта
python check_texts.py --report --glossary glossary-qq.toml . # сводка по правилам
python check_texts.py --only dash,meta-leaks --max 20 docs   # часть правил
```

Пустой вывод и код 0 означают, что текст можно показывать людям. Нужен Python
3.11 или новее, сторонних пакетов нет.

## Как дополнять

Новое правило добавляется в `rules.toml` (или в словарь проекта), затем
`python build.py` пересобирает `SKILL.md` и `PROMPT.md`. Правила с примерами и
объяснением дописываются в `RULES.md` руками: этот файл машиной не
собирается, он первичен для людей.

Перед тем как добавить запрет, стоит прогнать его по корпусу одобренных
текстов: правило, которое бракует хороший текст, вредит больше, чем
пропущенный оборот.

## Откуда взято

Первый слой частично из открытого скилла
[humanizer-ru](https://github.com/ilyautov/humanizer-ru) (Илья Утов, MIT):
списки пустых вводных, штампов, канцелярита и калек. Что взято и что
сознательно не взято, перечислено в приложении к `RULES.md`. Остальное
это решения автора курса «Учи Кванты!», накопленные за лето 2026 года.
